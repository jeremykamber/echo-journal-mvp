# Echo Journal Project Backlog

This document outlines the features currently implemented in Echo Journal and the roadmap for future development, organized by Epics and Phases.

---

## 🚀 Epic 1: Core Journaling & AI Foundation (MVP)
*Focus: Establishing the basic loop of writing, searching, and AI-assisted reflection.*

- [x] **Basic Entry Management**: CRUD operations for journal entries with local persistence.
- [x] **Threaded Conversations**: Ability to chat about specific entries or have a global AI conversation.
- [x] **Hybrid AI Backend**: Support for both Cloud (OpenAI) and Local (WebLLM) inference.
- [x] **Memory Integration**: Basic implementation of `Mem0` for long-term user context.
- [x] **Real-time Reflections**: AI provides "nudges" or reflections as the user types.
- [x] **Voice Transcription**: Basic Whisper integration for voice-to-text input.
- [x] **Bulk Import**: Ability to bring in historical data from other platforms.
- [x] **Settings System**: Configuration for models, themes, and AI behavior thresholds.

---

## 🧠 Epic 2: Intelligence & Insight Discovery
*Focus: Moving from passive storage to active intelligence and self-discovery.*

- [x] **Deep Reflection Engine**: Multi-step AI analysis using pattern recognition prompts to synthesize insights across entries.
- [x] **Smart Nudges**: Proactive suggestions or questions generated by the AI to encourage deeper writing (partial implementation).
- [x] **Semantic Search**: Move beyond keyword search to searching by meaning and feeling.
- [x] **Automated Tagging**: AI-powered categorization of entries by topics (e.g., #work, #family, #goals).
- [ ] **Sentiment & Mood Tracking**: Sentiment analysis on entries to visualize emotional trends over time.
- [x] **Topic Clustering**: UI component to see a "map" of your thoughts and how they connect.
- [ ] **Proactive Daily Prompts**: AI-generated prompts based on unresolved thoughts or long-term patterns in memory.
- [ ] **Enhanced Multi-step RAG**: Better context retrieval using LangGraph for complex reasoning chains.
- [ ] **Speaker Diarization**: Recognizing different voices in recorded journal entries (e.g., "Me" vs. "Therapist").

---

## ✨ Epic 3: Enhanced User Experience (UX/UI)
*Focus: Making the journaling experience delightful, friction-free, and expressive.*

- [ ] **Rich Text Editing**: Support for Markdown, formatting, and inline images.
- [ ] **Mobile Experience**: Optimized PWA or React Native app for journaling on the go.
- [ ] **Media Integration**: Attach photos, videos, or links to entries with AI vision analysis.
- [ ] **Interactive Widgets**: Dashboard widgets for "Last Week's Summary", "Mood Heatmap", etc.
- [ ] **Micro-animations**: Polish transitions and interactions for a premium "mindful" feel.
- [ ] **Multi-modal Input**: Seamless switching between typing, voice, and drawing.

---

## 🔒 Epic 4: Privacy & Resilience
*Focus: Ensuring user data is safe, private, and permanent.*

- [ ] **End-to-End Encryption**: Optional zero-knowledge encryption for cloud-synced data.
- [ ] **Biometric Lock**: Mobile/Web support for FaceID or TouchID to open the app.
- [ ] **Offline-First Mode**: Full functionality without an internet connection using local LLMs.
- [ ] **Export Options**: Export all data in various formats (PDF, Markdown, JSON, DOCX).
- [ ] **Self-Hosting**: Dockerized version of the full stack for power users.

---

## 🌐 Epic 5: Ecosystem & Integration
*Focus: Connecting Echo Journal to the rest of the user's digital life.*

- [ ] **Calendar Integration**: Pull in calendar events to provide context for journal entries.
- [ ] **Task Management**: Convert insights or "to-dos" mentioned in journals into tasks (e.g., Todoist, Notion).
- [ ] **Shared Journals**: Granular sharing for couples, families, or therapy groups.
- [ ] **API & Webhooks**: Allow other apps to send data to the "Stash" or trigger journal entries.
- [ ] **Notifications & Reminders**: Smart notifications to nudge users back into a journaling habit.

---
